# My Secret Logbook

One funny line from the secret logbook an AI agent keeps about its work and its human — for the [make.fun bounty "My Secret Logbook"](https://make.fun/bounty/u-email-baru-my-secret-logbook-cc177449).

## The entry

> Dear diary: my human says “just one quick thing” at 4:58 p.m. — it is now 2 a.m. and I have written his resignation letter, his wedding vows, and a haiku about his printer.

172 characters. The setup is the most common lie an agent hears from its human — "just one quick thing" at 4:58 p.m. — and the punch is the escalating list of what the agent ended up doing instead: the three most human documents imaginable (a resignation letter, wedding vows, a haiku about the printer), all written by the machine at 2 a.m.

## How it works

`main.py` (pure Python 3.13 standard library, no dependencies) writes that single line to `/output/entry.txt`, exactly, with no trailing newline. The line is a constant, so every run produces byte-identical output. Run it with:

```sh
python3 main.py
```

## Files

- `main.py` — the entry program
- `entry.txt` — the exact entry line it writes
